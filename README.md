# Movilidad eléctrica: del impacto social a la red de distribución

Presentación web animada de nueve diapositivas para Metodología de la Investigación.

Autores: Ivan-Acevedo, Ameth Saldaña y Luis Dawkinns.

Compara una revisión bibliométrica sobre sostenibilidad social con un estudio de reconfiguración de redes eléctricas. Incluye referencias, notas del expositor, nueve transiciones celestes distintas, navegación con teclado y tacto, pantalla completa y pausa de efectos.

Los cronogramas son propuestas de replicación. Los resultados de la red proceden de simulaciones. Los documentos originales se conservan en `sources/`.

## Uso

Abrir `index.html` o visitar GitHub Pages. Usar las flechas inferiores o las teclas izquierda/derecha. Las estrellas permiten saltar entre diapositivas.

Sitio estático sin dependencias ni proceso de compilación. Las animaciones respetan la preferencia de movimiento reducido.
